
=====================================================================
 PARTIE 3 : CONFIGURATION MPLS / LDP
=====================================================================


EBOLOWA(config)#
ip cef
mpls label range 1000 1999
mpls label protocol ldp
mpls ldp router-id loopback0
interface e0/0
 mpls ip
 exit
interface e0/1
 mpls ip
 exit

=====================================================================
 PARTIE 4 : COMMANDES DE VÉRIFICATION UTILISÉES
=====================================================================

! Table de commutation de labels (tous les routeurs)
show mpls forwarding-table
show mpls forwarding-table 11.11.11.11 32      (BUEA)
show mpls forwarding-table 99.99.99.99 32      (YAOUNDE)
show mpls forwarding-table 22.22.22.22 32      (BERTOUA)

! Bindings
show mpls ip binding                           (EBOLOWA, puis autres routeurs)
show mpls ldp bindings                         (MAROUA)
show mpls ldp binding 11.11.11.11 32           (EBOLOWA)
show mpls ldp binding 99.99.99.99 32           (GAROUA)
show mpls ldp binding 33.33.33.33 32           (YAOUNDE)
show mpls ldp binding 22.22.22.22 32           (BERTOUA)

! Voisins LDP
show mpls ldp neighbor                         (YAOUNDE, NGAOUNDERE, DOUALA,
                                                MAROUA, puis autres routeurs)

! Traceroute MPLS (affiche les labels)
BERTOUA#traceroute 33.33.33.33 source lo0
EBOLOWA#traceroute 44.44.44.44 source lo0
BERTOUA#traceroute 22.22.22.22 source lo0

=====================================================================
 PARTIE 5 : OPTIONS ET DÉPANNAGE
=====================================================================

! Désactiver PHP (Penultimate Hop Popping)
Rx(config)#mpls ldp explicit-null

! Forcer le router-id LDP sur la loopback 0
Rx(config)#mpls ldp router-id loopback 0 force

! Commandes de dépannage LDP
show mpls interfaces
show mpls ldp neighbor
show run int
show run | in mpls

Problèmes possibles :
 1. mpls ip non activé (MPLS IP manquant sur les interfaces connectées)
 2. incompatibilité de protocole (TDP/LDP), global ou au niveau interface
 3. loopback au plus grand ID prise comme router-id mais non annoncée dans l'IGP
 4. authentification non concordante, si configurée
 5. filtrage du port 646 (paquets LDP)

=====================================================================
 NOTES (anomalies relevées dans le PDF d'origine)
=====================================================================
NB 1 - Descriptions d'interfaces à vérifier :
       * GAROUA : e0/0 est décrite « -> MAROUA » et e0/1 « -> NGAOUNDERE »,
         alors que d'après la topologie e0/0 (4.4.4.0/28) va vers NGAOUNDERE
         et e0/1 (1.1.1.0/28) vers MAROUA : les deux descriptions sont inversées.
       * BAFOUSSAM : e0/0 est décrite « -> BAMENDA » alors que la liaison
         10.10.10.0/28 va vers BUEA.
NB 2 - Dans le PDF, la config OSPF de NGAOUNDERE (seul 4.4.4.0 visible) et
       DOUALA (seul 66.66.66.66 visible) est incomplète, et celle de BERTOUA
       et EBOLOWA est absente. Les lignes marquées « déduit » sont à
       confirmer avec vos fichiers de config.
NB 3 - GAROUA : « interface e1/0 » dans le PDF, alors que GAROUA n'a que
       e0/0 et e0/1 (la table de commutation utilise Et0/1) : c'est
       vraisemblablement e0/1.
